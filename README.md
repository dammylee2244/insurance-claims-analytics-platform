# Insurance Claims Analytics Platform

An end-to-end insurance analytics platform simulating enterprise claims processing, fraud detection, operational reporting, and policyholder risk intelligence using a medallion architecture approach.

## Features

- Bronze / Silver / Gold architecture
- Claims enrichment pipelines
- Policyholder risk scoring
- Suspicious claims detection
- Claims fraud watchlists
- Adjuster workload analytics
- SQLite analytics warehouse
- Streamlit operational dashboard
- Executive KPI reporting

## Tech Stack

- Python
- Pandas
- SQLite
- Streamlit
- Jupyter Notebook

## Architecture

Bronze → Silver → Gold → SQL Warehouse → Dashboard

## Key Analytics

- Claims exposure analysis
- Fraud risk scoring
- Operational workload monitoring
- Claims investigations
- Executive reporting
